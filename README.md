# API REST - Gestión de Clientes

Proyecto desarrollado para la asignatura Taller de Plataformas Web, semana 9.

## Tecnologías
- Node.js
- Express.js
- MySQL
- Postman

## Funcionalidades
- GET /clientes: consultar clientes.
- POST /clientes: crear clientes.
- PUT /clientes/:id: actualizar clientes.
- DELETE /clientes/:id: eliminar clientes.

## Ejecución
1. Instalar Node.js y MySQL.
2. Crear la base de datos gestion_clientes y su tabla clientes.
3. Instalar dependencias con npm install.
4. Configurar la variable de entorno DB_PASSWORD con la contraseña local de MySQL.
5. Ejecutar el servidor con node index.js.

La API funciona en http://localhost:3000.
